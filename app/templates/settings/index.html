Инструкция по подключению Google Cloud
  1. Создайте проект в Google Cloud Console и включите Drive API, Sheets API, Picker API.
  2. Настройте OAuth consent screen: scopes openid, userinfo.email, drive.file.
  3. Для @gmail.com переведите приложение в статус «In production» (иначе refresh token живёт 7 дней).
  4. Создайте OAuth Client (Web application) с redirect URI {{ request.base_url }}settings/google/oauth/callback.
  5. Задайте переменные окружения из .env.example и перезапустите приложение.
